Why the prompt is built this way

    
    
      
  • Your details are passed in labelled fields, and blank fields are marked [not provided], so the assistant knows exactly what to leave as a placeholder.
    • 
      
  • The word limit is stated as a hard ceiling that covers everything except the subject line, which leaves no doubt about what is counted.
    • 
      
  • The prompt forbids inventing names, dates, numbers and reasons, and says a reason may appear only if you supplied one.
    • 
      
  • Placeholders have one fixed style, [Descriptive Name], so they are easy to find and fill in before sending.
    • 
      
  • The assistant returns only the email, with no commentary, so the result can be pasted straight into a mail client.
