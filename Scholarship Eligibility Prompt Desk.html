Why the prompt is built this way

    
    
      
  • Missing data is checked first, so a low score with no income gets INSUFFICIENT_DATA instead of a rejection based on a guess.
    • 
      
  • “At least” and “must not exceed” are written as ≥ and ≤, which settles the boundary values.
    • 
      
  • Indian digit grouping (3,00,000) is declared equal to 300000, so it is never misread.
    • 
      
  • Only the two criteria are used; names, caste, essays and other details are ignored.
    • 
      
  • The output is a single label with no extra text, so another system can read it directly.
